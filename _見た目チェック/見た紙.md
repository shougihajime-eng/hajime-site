# ホームページの見た目チェック（2026-11-09・公開前）
手元の組み立て（next start）を Chrome で撮った。トップ（/）と はじめての将棋（/hajimete-shogi）を 4つの大きさで。横のはみ出し＝全部0px（機械で測った）。

| 点 | 結果 |
|---|---|
| 駒の五角形 | アプリのアイコン（筆の「はじめ」駒）は正しい五角形のまま。ページに盤の駒は無い（電話の中の絵はお店の写真） |
| 駒の字 | アイコンの字は駒の真ん中・切れなし |
| 持ち駒 | ページに無し（対象外） |
| 書体 | 見出し・本文・ボタンとも場所で変わらない |
| ずれ | iPad よこ・たて＝写真左・名前右。iPhone・SE＝写真→名前のたて並び。ずれ無し |
| 重なり | 字が写真・ボタンにかぶる所なし。名前の判子は名前の右上で字にかからない |
| 問題画面 | 電話の中の画面写真は切れずに入っている |
| 余白 | 先頭画面に大きな空きなし |

写真＝本人「前のほうがよかった」「げんきなやつ」で、前の元気な笑顔（hajime-portrait.png を3:4に切った hajime-portrait-genki.webp）に戻して撮り直した。4つとも顔が切れず、字にかからない。
